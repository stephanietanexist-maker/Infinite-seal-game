No wifi dinosaur game but with a seal! :D

Use the up arrow or spacebar to jump. The score is displayed at the top left corner of the board. 

Game tutorial used: https://www.youtube.com/watch?v=lgck-txzp9o

AI was used to make a code so the hitbox smaller since sometimes the seal wouldn't be touching it but somehow dies. The rest of the code I learned from the youtube tutorial!
